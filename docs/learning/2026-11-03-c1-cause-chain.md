## #146 구현과 리뷰

호출 체인의 service는 기존 ResourceRef(kind/name)를 재사용한다. 각 단계 근거 번호를 검증하되 근거가 사라진 단계를 삭제하지 않는다. 체인 누락·종점 불일치·근거 없는 단계·종점의 downstream 오류 전달을 v1 stop_check가 감지해 기존 1회 재조사를 사용한다. 공통 판단에서도 유효한 체인이 없으면 candidate로 제한하고 기존 guess 조건은 유지한다. 과거 JSON은 기본 빈 목록으로 읽고 저장된 판단을 다시 쓰지 않는다. 화면은 접힌 체인/근거 링크를 추가하며 Slack의 기존 판단/근거 설명 경로를 유지한다. 구현된 조사 버전은 v1뿐이고 v2는 없다.

GPT-6.1 Sol Medium 독립 리뷰에서 실패한 도구 근거가 재조사를 우회할 수 있는 P2 한 건을 확인했다. 실패 Observation을 체인 근거에서 제외하고 사전 로그 실패도 Observation으로 보존했다. 초기 신호·증상 근거는 계속 허용한다. 재현 회귀 테스트를 추가했고 재리뷰의 잔여 지적은 없다.
