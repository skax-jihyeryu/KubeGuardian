# #189 새 이력 채팅 검증

## 자동 검증
- 새 POST가 없을 때 회귀 3건 실패 확인(404), 구현 후 chat_pages 17건 통과.
- 전체 pytest 1,756건 통과(28.38s), Ruff check/format 및 diff check 통과.
- 이전 DB 기록 보존, 새 UUID 발급·재열기 유지, 후속 질문 ID, 목록 필터·점검·이슈 맥락, 잘못된 맥락 시 쿠키 유지 검증.

## 브라우저 검증
실환경 대화에 테스트 질문을 남기지 않도록 별도 DB와 localhost 8082 검증 서버 사용. AI 답변은 제어된 4초 지연 응답으로 대체했다. Kubernetes 상태나 Slack을 변경하지 않았다.

- 점검 #2에서 질문 패널 열기 → 새 채팅 버튼 및 현재 맥락 확인.
- 4초 지연 새 채팅 요청 중 새 채팅·보내기 비활성화. Escape 후 응답이 와도 패널이 다시 열리지 않음.
- 4초 지연 답변 중 새 채팅 비활성화, 완료 후 활성화.
- 새 채팅 POST 503 주입: 기존 답변·입력 초안 유지, 오류 표시, 재시도 가능.
- 성공 재시도: 답변·초안 제거, 예시 질문 복원, 점검 #2 맥락 유지. 새로고침 후에도 빈 대화 유지.
