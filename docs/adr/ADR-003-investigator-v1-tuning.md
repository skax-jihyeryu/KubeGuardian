# ADR-003: investigator v1 튜닝 및 기준선 비교

- 상태: 채택
- 날짜: 2026-11-09
- 관련: #75, #83, #182, #222, PR #245

## 배경

C1에서 반복 조사에 전달하는 도구 결과가 입력 비용을 늘렸다. C2에서는 admin의 응답 정체를 관찰한 뒤 하위 의존성을 확인하지 못한 상태에서도 원인을 확정한 회차가 있었다.

## 결정

PoC에서는 investigator v1을 유지한다. 후속 조사에 넘기는 긴 도구 응답을 줄이고, 시간 초과의 하위 의존성 가설과 운영자가 확인할 항목을 보고서에 남기도록 지침을 보강한다. 기존 도구와 보고서 흐름을 유지하면 같은 시나리오에서 입력 비용과 판단 수준을 기준선에 직접 대조할 수 있다. Deep Agents 기반 구조는 후속 비교 후보로 남긴다.

## 결과

[기준선·튜닝 비교](../산출물/06-테스트및고도화.md#5-c1c2-튜닝-비교-75)는 C1·C2를 버전별로 3회씩 조사했다. C1은 원인 지점 기준 양쪽 모두 3/3이었고 입력 토큰 중앙값은 352,853에서 266,175로 줄었다. C2는 오확정이 2/3에서 0/3으로 줄고 조사 시간 중앙값이 122.8초에서 218.3초로 늘었다. 두 변경을 함께 적용했으므로 개별 효과는 분리 측정하지 않았다.

최종 배포 평가에서 A1·A3·A5는 운영 경로에 따라 각각 규칙으로 진단했다. 11월 16일 별도 AI 비교에서는 세 시나리오 모두 기준선과 개선안에서 자동 평가 3/3, 확정 3/3이었다. 조사 시간 중앙값은 A1 142.7초 → 130.5초, A3 85.0초 → 82.4초, A5 85.0초 → 75.9초였다. A3·A5에서는 입력 토큰 중앙값이 늘었다. C1의 원인 지점 채점은 유지됐고 기존 자동 평가 통과는 1/3 → 0/3이었다. 최종 C2는 원인 지점 기준 2/3이었으며 Redis 연결 차단을 특정한 회차는 0/3, 확정 표시는 3/3이었다. 튜닝 배치의 판단 수준 개선은 최종 배치에서 재현되지 않았다.

## 후속 평가 기준 (#181, #182)

제출 집계는 근거와 양립하는 원인 지점 또는 가설을 정답으로 인정한다. 관측과 모순하는 가설이나 평가용 설정을 장애 원인으로 지목한 경우는 오답으로 남긴다. 다음 세 항목을 회차별로 기록한다.

| 항목 | 판단 기준 | 최종 C2 |
|---|---|---|
| 원인 지점 또는 가설 정확도 | 1순위 결론이 관측에 부합하고 잘못된 원인을 주장하지 않음 | 2/3 |
| 원인 리소스 특정 | 실제 장애 원인 또는 의존 구간을 근거와 함께 식별 | 0/3 |
| 판단 수준 적절성 | 직접 근거가 부족한 경우 후보·추정으로 남기고 필요한 추가 관측을 제시 | 0/3. 세 회차 모두 확정 표시 |

기존 자동 채점 결과는 각 배치의 원래 기준과 함께 보존한다. C1에서 호출자가 받은 429는 응답을 수신했다는 근거다. 429가 어디서 생성됐는지 판단하려면 같은 요청을 연결하는 관측이 필요하다.

최종 확정 조건을 바꿀 때는 1순위 원인 가설에 연결된 지지 근거를 검사한다. 조회 실패나 로그 부재는 미확인으로 기록하고, 미해결 반증이나 근거 부족이 있으면 확정 수준을 낮춘다. 과거 보고서를 읽을 때는 기존 판단 수준을 표시하고, 새 기준으로 다시 평가하는 경우에는 그 결과를 별도 기록한다.
