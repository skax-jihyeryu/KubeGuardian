# 화면 목업 원본

Claude Design Artifact의 내려받은 사본(2026-11-02)이다.
출처: https://claude.ai/artifact/QAkY5tHryEFXWQmSGg3tqN

각 `.dc.html`은 화면·상태별 목업이고 `kg.css`는 공통 스타일이다.
`canvas.json`은 아트보드 배치 정보다. Claude 전용 `support.js`는 원본 다운로드에 포함되지 않았다.
제품 구현은 `docs/04-ui-spec.md`, `docs/04-1-ui-design.md`와 함께 이 마크업을 참고한다.
목업의 하드코딩된 예시 값은 실제 화면에서 SQLite 조회 결과로 대체한다.
